# Packet reference (Play state, 1.10 - 1.12.2)

_Generated by `tools/gen_docs.py` from the generated sources. Do not edit by hand._

Each packet is a Rust struct in `mcscon::packets::cb` (clientbound, decoded) or `mcscon::packets::sb` (serverbound, encoded). Field names are `snake_case` versions of the [minecraft-data](https://github.com/PrismarineJS/minecraft-data) names. Where versions differ in layout, the struct is the union of all layouts; fields a version does not have keep their default (0) on decode and are not written on encode. Types: `Str` UTF-8 view, `Bytes` raw/NBT view, `Slot` item stack, `Array<T>` lazily iterated validated array, `MetaView` entity metadata, `Option<T>` an optional field, `BlockPos` block coordinates, `Uuid` 16 bytes. Views borrow the receive buffer and are valid only inside the packet handler. See [packets](rust/packets.md) and [wire types](rust/wire.md).

The tables list the wire packet id (hex) per id table; 1.11.2 uses the 1.11 table and 1.12.1 the 1.12.2 table. `–` = the packet does not exist in that version. Nested helper structs (for example array elements) are defined next to their packet in `src/packets/`.
